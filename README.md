# Mini Social Feed

A full-stack social media application built using React.js, Node.js, Express.js, and MongoDB.

## Features

- User Signup
- User Login
- JWT Authentication
- Create Posts
- Public Feed
- Like Posts
- Comment on Posts

## Tech Stack

### Frontend
- React.js
- Material UI
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT
- bcryptjs

## API Endpoints

### Authentication
- POST /api/auth/signup
- POST /api/auth/login

### Posts
- POST /api/posts/create
- GET /api/posts
- POST /api/posts/:postId/like
- POST /api/posts/:postId/comment
